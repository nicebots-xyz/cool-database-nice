# hippo

Highly available PostgreSQL 18 for Docker Swarm: Patroni + etcd + HAProxy, deployed with a
single `docker stack deploy`, shipped as images that keep themselves up to date.

- **Design and decisions:** [`docs/design.md`](docs/design.md)
- **Lab experiments behind the design:** [`lab/README.md`](lab/README.md)

> Status: early development. Nothing is released yet.
